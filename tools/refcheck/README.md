# ตัวเทียบกับระบบอ้างอิง

ใช้ตรวจว่าชั้นวิเคราะห์ (`js/analysis.js`) ให้ผลตรงกับระบบอ้างอิง ทั้งลักษณะดวง กำลังดิถี และชุดธาตุดี/ร้าย
ไฟล์ในโฟลเดอร์นี้ใช้ภายในเท่านั้น ไม่ได้รวมอยู่ในแอป

## ผลล่าสุด

| ชุดข้อมูล | จำนวน | ตรงกัน |
|---|---|---|
| ทุกผังที่ผูกได้ (ปี 60 × เดือน 12 × วัน 60 × ยาม 12) | 518,400 | 100% |
| วันเกิดจริงสุ่ม ค.ศ. 1901–2098 (ผูกด้วย BaziCore ค่าตั้งต้น เวลาไทย) | 100,000 | 100% |
| วันเกิดจริงเดือน ม.ค./เม.ย. (ช่วงที่ผลขึ้นกับวันในเดือน) | 50,000 | 100% |

ก่อนรอบนี้ (ใช้ตารางสรุปเดิม) วัดกับข้อมูลชุดเดียวกันได้: ลักษณะดวง 97.5% · ธาตุดี 74.7% ธาตุร้าย 90.9% (ถ้านับแบบไม่แยกเงื่อนไข ธาตุดี/ร้ายตรงกัน 90%)

สาเหตุที่ไม่ตรงในรอบก่อน (แก้แล้วทั้งหมด):
1. คะแนนฝ่ายช่วยขาดโบนัส +2 เมื่อกิ่งครบชุดรวมทิศ/รวมสามของธาตุดิถี และเพดาน 9.9
2. ลำดับก้านแฝงของ ฉลู วอก จอ ไม่ตรง ทำให้กำลังก้านแฝงคลาด (มีผลกับดวงสละดิถี)
3. เกณฑ์เปิดทางดวงสละดิถีและดวงกระแสยังหยาบ (ไม่ดูรากแฝงในกิ่งคลัง ไม่ดูธาตุต้านที่หมดแรง)
4. ธาตุดี/ร้ายของดวงปกติใช้ตารางที่มีช่องว่าง และไม่รองรับธาตุที่มีเงื่อนไข (เช่น ไม้ถ้ามากับไฟ ดินเฉพาะฉลู/มะโรง บางตัว)
5. ยังไม่มีการปรับอุณหภูมิ (เกิดฤดูหนาวเพิ่มไฟ ฤดูร้อนเพิ่มน้ำ) และการตัดธาตุซ้ำระหว่างดี/ร้าย
6. ยังไม่มีการแปรธาตุ (มีผลราว 1.4% ของผัง)

## ไฟล์

- `check.js` — เทียบ `js/analysis.js` กับผลที่บันทึกไว้ (`node tools/refcheck/check.js` ทั้งหมด ราว 7 วินาที · `--step 50` สุ่มตรวจ) ชุดทดสอบหลักเรียกแบบสุ่มตรวจ 1 ใน 5
- `data/ref-all.tsv.gz` — ผลของระบบอ้างอิงทุกผังที่ผูกได้: เสา 8 ตัวเลข (1-based ยาม วัน เดือน ปี) · ลักษณะดวง · กำลังดิถี · คะแนน · รหัสธาตุดี ร้าย กลาง · ธาตุจริงหลังแปรธาตุ
- `data/ref-dates.tsv.gz` — ผลของวันเกิดจริง 150,000 ราย
- `harness/` — ตัวรันระบบอ้างอิงบน Java (สร้าง stub ของคลาส Android แล้วเรียกขั้นวิเคราะห์โดยตรง)

## สร้างตัวเทียบใหม่ (เมื่อระบบอ้างอิงออกรุ่นใหม่)

ต้องมีไฟล์ APK ของระบบอ้างอิง (ไม่เก็บใน repo) java 17+ python3 และ dex2jar

```sh
REF_PKG=<ชื่อแพ็กเกจของแอป> D2J=/path/to/d2j-dex2jar.sh \
  sh tools/refcheck/harness/build.sh /path/to/app.apk /tmp/refwork
node tools/refcheck/harness/gen.js > /tmp/all.txt          # ผังทั้งหมด 518,400 แบบ
MAIN=H2 sh tools/refcheck/harness/run.sh /tmp/refwork < /tmp/all.txt > /tmp/dump.tsv
```

`run.sh` อ่านบรรทัดละผัง "ก้านยาม กิ่งยาม ก้านวัน กิ่งวัน ก้านเดือน กิ่งเดือน ก้านปี กิ่งปี [ปี เดือน วัน ชม. นาที]"
ถ้าไม่ใส่วันเกิดจะใช้ 12 เม.ย. 2000 12:00 (มีผลเฉพาะดิถีน้ำเดือนมะโรง/ฉลูที่ดูช่วงต้นเดือน)

หมายเหตุรหัสธาตุภายใน: 0 ทอง 1 น้ำ 2 ไม้ 3 ไฟ 4 ดิน · รหัสพิเศษอธิบายไว้ในหัว `js/analysis.js` ส่วนที่ 5
