# Bazi Pro · ผังดวงสี่เสา

แอปดูดวงจีนสี่เสา (八字) ที่ตั้งเป้าให้คำอธิบายระดับมืออาชีพเป็นภาษาคน แบ่งเป็น 3 ชั้น:

1. **ชั้นคำนวณ** (ทำแล้ว): 6 เสา, วัยจร, เวลาสารท, เวลาสุริยะ
2. **ความสัมพันธ์** (`js/interactions.js`): ก้านรวม/ก้านปะทะ, ภาคีสามประสาน ภาคีฤดู ภาคีครึ่ง ภาคีคู่, ปะทะ, การลงโทษ, การทำร้าย ทั้งในดวงเดิมและกับวัยจร/ปีจร
3. **ชั้นเล่าเรื่อง** (`js/narrative.js`): คำทำนาย 11 หัวข้อ (ตรวจทานแล้ว) รวมทิศบ้านและนิสัยตามนักษัตร + คำทำนายวัยจร/ปีจร/เดือนจร แยกสิบเทพ · ศัพท์ใช้ตามระบบอ้างอิง (ดิถี ราศีบน/ล่าง คู่ธาตุ…เสริมหลัก ไตรภาคี ล่างชง เฮ้ง ไห่ ผั่ว) ทุกย่อหน้ามีที่มา
5. **ดวงที่บันทึก** (`js/store.js`): เก็บใน localStorage ของเบราว์เซอร์ (ยังไม่มีฐานข้อมูลออนไลน์) ดวงของฉัน 1 ดวง + ดวงอื่น สำรอง/นำเข้าเป็นไฟล์ JSON
7. **บุคลิกตามเสาวัน** (`js/daypillar.js`): 60 แบบ ภาพการ์ด SVG วาดจากดิถี + เวลา/ฤดู/ธาตุของราศีล่าง · การงาน การเงิน ความรัก ดึงจากทั้งดวง
6. **สรุปปี** (`js/yearly.js`): อ่านทีละด้าน (งาน เงิน ความรัก สุขภาพ) 12 เดือน เดือนที่ดีที่สุด ไท้ส่วย · ดวงรายวันและรายยาม (เมนู วันนี้ & ฤกษ์)
9. **โหมดคนทั่วไป / มืออาชีพ** (`js/plain.js`, `js/shensha.js`): โหมดทั่วไปเล่าแบบคำตอบก่อน (หัวเรื่อง เหมาะทำ/ควรเลี่ยง แถบ 4 ด้าน ระดับ ดี/กลาง/ควรระวัง) เหตุผลทางดวงพับไว้ · โหมดมืออาชีพแสดงเต็ม ระดับ 5 คำพร้อมคะแนน · ดาวพิเศษ 6 ดวง
10. **ปฏิทินพื้นฐาน** (`js/almanac.js`): 12 เทพประจำวัน (建除) แสดงในหน้าวันนี้และใช้กรองหาฤกษ์ · กงหวั่ง (空亡) ในพื้นดวงและเมื่อเสาจรตกกงหวั่ง
8. **หาฤกษ์ตามดวงส่วนตัว** (`js/auspicious.js`): 6 เรื่อง ช่วงไม่เกิน 3 เดือน 5 อันดับพร้อมยามดี ฤกษ์แต่งงานเช็กดวงทั้งสองคน (ไม่ใช่ปฏิทินจีน 通书)
4. **ดวงคู่** (`js/compat.js`): ตำรามาตรฐาน 合婚 คะแนน 6 ด้าน รวม 100 (ธาตุเติมกัน ดิถีคู่กัน วังคู่ครอง ดาวคู่ครอง นักษัตรปีเกิด ราศีล่างเดือน)
4. **ชั้นวิเคราะห์** (`js/analysis.js`): คะแนนฝ่ายช่วย → การแปรธาตุ (รวมทิศ รวมสาม ภาคีครึ่ง ภาคี 6 ก้านรวม ธาตุโดดถูกข่ม) → ลักษณะดวง (กระแส สละดิถี 2 ธาตุ) → กำลังดิถี (แข็ง/สมดุล/อ่อน/มีโรคใช้ยา) → ธาตุให้คุณ/ให้โทษ/กลาง รวมธาตุที่มีเงื่อนไข (เฉพาะราศีบน/ล่าง เฉพาะกิ่งบางตัว แยกขั้ว ถ้ามากับธาตุอื่น) และการปรับอุณหภูมิ
   ตรวจเทียบกับระบบอ้างอิงครบทุกผังที่ผูกได้ 518,400 แบบ และวันเกิดจริง 150,000 ราย ตรงกัน 100% (`node tools/refcheck/check.js` · วิธีสร้างตัวเทียบใน `tools/refcheck/README.md`) · โครงสร้างดวง 格局 แสดงในโหมดมืออาชีพ (`js/structure.js`)
11. **AI เรียบเรียงและถามดวง** (`js/ai.js`): ปุ่มเรียบเรียงคำทำนายทั้งหน้า และเมนูถามดวง ส่ง "แฟ้มดวง" (ผลที่แอปคำนวณแล้ว + คำทำนายแม่แบบ) ให้ AI เขียน ห้าม AI คำนวณหรือเปลี่ยนผลวิเคราะห์เอง ถ้าต้องการข้อมูลเพิ่มให้เรียกเครื่องมือของแอป (ดวงรายปี รายเดือน รายวัน หาฤกษ์ ดวงคู่) · บน claude.ai ใช้ Claude ผ่านบัญชีผู้ใช้ ที่อื่นใช้ปุ่มคัดลอกไปวางใน AI ตัวไหนก็ได้ · ผลและประวัติเก็บในเครื่องแยกตามดวง · ตัวกลาง `provider()` รอเพิ่มผู้ให้บริการอื่น (กุญแจ API ของผู้ใช้หรือเซิร์ฟเวอร์กลาง)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `js/astro.js` | Julian Day, ΔT, ตำแหน่งดวงอาทิตย์ (VSOP87 แบบย่อ), เวลาสารท 24, สมการเวลา |
| `js/bazi-core.js` | `BaziCore.calculate(input)` คืนค่า 6 เสา, ราศีแฝง, สิบเทพ, จำนวนธาตุ, วัยจร 10 ช่วง และคำเตือนเวลาใกล้รอยต่อ |
| `index.html` | หน้าทดลอง (โหลดสคริปต์จาก `js/`) |
| `build.js` | `node build.js` สร้าง `dist/index.html` แบบไฟล์เดียว |
| `tests/run.js` | `node tests/run.js` ทดสอบกับค่าอ้างอิงที่รู้กันทั่วไป |

ไม่มีไลบรารีภายนอก ใช้ได้ทั้งเบราว์เซอร์และ Node

## ตัวอย่างการใช้

```js
const r = BaziCore.calculate({
  year: 1990, month: 1, day: 15, hour: 10, minute: 30,
  gender: 'M', tz: 7, longitude: 100.5,
  options: { yearChange: 'winterSolstice' } // ค่าอื่นใช้ค่าตั้งต้น
});
r.pillars.year.zh   // '庚午'
r.luck.periods[0]   // วัยจรช่วงแรก
```

## ตัวเลือก (ค่าตั้งต้นตามระบบที่ตกลงกันไว้)

| ตัวเลือก | ค่า |
|---|---|
| `yearChange` | `winterSolstice` ตังจี่ (ค่าตั้งต้น) · `lichun` ลิบชุง · `summerSolstice` แฮ่จี่ |
| `ziHour` | `midnight` วันเปลี่ยน 24.00 น. (ค่าตั้งต้น) · `at23` วันเปลี่ยน 23.00 น. |
| `luckMethod` | `standard` นับจากวันเปลี่ยนปี (ค่าตั้งต้น) · `academic` นับจากวันเกิด ตามตำรา · `proportional` สัดส่วนช่วงเดือน นับละเอียดเป็นวัน |
| `monthSystem` | `standard` เปลี่ยนเดือนที่ 节 · `zhongqi` เปลี่ยนเดือนที่ 中气 |
| `trueSolarTime` | `false` เวลามาตรฐาน (ค่าตั้งต้น) · `true` เวลาสุริยะปรากฏ |
| `southern` | ซีกโลกใต้ (กิ่งเดือนเลื่อน 6) |
| `pregnancyMonths` | 9 (ใช้คำนวณหลักปฏิสนธิ) |

## ผลการตรวจสอบ

ตรวจกับระบบอ้างอิงด้วยวันเกิดสุ่มหลายหมื่นเคส (ครึ่งหนึ่งจงใจให้อยู่ใกล้สารท):

- **เวลาสารท:** ตรงกับตารางอ้างอิงภายใน ±1 นาทีทุกรายการ ช่วง ค.ศ. 1601–2069 (หลังจากนั้นขึ้นกับการคาดการณ์ ΔT)
- **ค่าตั้งต้น (เปลี่ยนปีที่ตังจี่):** 6 เสา ทิศวัยจร อายุเริ่ม และวันเริ่มวัยจรทุกช่วง ตรงกัน 100%
- **เปลี่ยนปีที่ลิบชุง/แฮ่จี่:** ต่างราว 1 ใน 2,000 เคส เฉพาะคนที่เกิดภายในประมาณ 5 ชั่วโมงก่อน/หลังสารทเปลี่ยนปีแต่คนละวันปฏิทิน ระบบอ้างอิงหาเสาปีด้วยค่าเฉลี่ยความยาวปี จึงให้ผลเสาปีกับเสาเดือนขัดกันเอง (เช่น 3 ก.พ. 1733 23:22) ตัวนี้ยึดเวลาสารทจริง
- **โหมดเวลาสุริยะ:** ในวันที่ตรงกับสารท ระบบอ้างอิงเอาเวลามาตรฐานไปเทียบ แต่วันอื่นใช้เวลาสุริยะ ตัวนี้ใช้เวลาสุริยะตลอด ผลจึงต่างกันได้เฉพาะคนที่เกิดในวันสารทนั้น
- **วิธีอายุแบบสัดส่วนช่วงเดือน:** วันเริ่มวัยจรของระบบอ้างอิงมักเร็วกว่า 1 นาที เพราะตัดเศษวินาทีทิ้งตอนแปลงวันที่

## ข้อจำกัดที่ทราบ

- ก่อน 1 เม.ย. 1920 ประเทศไทยใช้เวลา UTC+6:42 ผู้ใช้ต้องใส่ `tz` เอง (แอปขึ้นคำเตือนให้)
- ยังไม่รองรับปฏิทินจูเลียน (ก่อน ค.ศ. 1583)
