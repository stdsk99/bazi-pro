# ผังดวงสี่เสา (bazi-pro)

แอปดูดวงจีนสี่เสา (八字) ที่ตั้งเป้าให้คำอธิบายระดับมืออาชีพเป็นภาษาคน แบ่งเป็น 3 ชั้น:

1. **ชั้นคำนวณ** (ทำแล้ว): 6 เสา, วัยจร, เวลาสารท, เวลาสุริยะ
2. **ความสัมพันธ์** (`js/interactions.js`): ก้านรวม/ก้านปะทะ, ภาคีสามประสาน ภาคีฤดู ภาคีครึ่ง ภาคีคู่, ปะทะ, การลงโทษ, การทำร้าย ทั้งในดวงเดิมและกับวัยจร/ปีจร
3. **ชั้นวิเคราะห์** (`js/analysis.js` + `js/analysis-tables.js`): ใช้เกณฑ์ที่ตกลงกันไว้ — คะแนนฝ่ายช่วย → ดวงพิเศษ (สละดิถี/กระแส/ภาคี) → ประเภทดวงปกติ (แข็ง/สมดุล/อ่อน/มีโรคใช้ยา) → ธาตุให้คุณ/ให้โทษ
   ผลเทียบ 100,000 ดวง: คะแนนตรง 100%, ลักษณะดวง 98.4%, ธาตุดี/ร้าย 94.0% · ยังไม่ทำ: การแปรธาตุจากการรวม/ชง (~1.2% ของดวง), สิบเทพเชิงความหมาย, ผลของวัยจร
3. **ชั้นเล่าเรื่อง** (ยังไม่ทำ): ส่งผลวิเคราะห์ให้ AI เรียบเรียงเป็นภาษาคน (เรียกผ่านเซิร์ฟเวอร์ ห้ามฝังกุญแจในแอป)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `js/astro.js` | Julian Day, ΔT, ตำแหน่งดวงอาทิตย์ (VSOP87 แบบย่อ), เวลาสารท 24, สมการเวลา |
| `js/bazi-core.js` | `BaziCore.calculate(input)` คืนค่า 6 เสา, ราศีแฝง, สิบเทพ, จำนวนธาตุ, วัยจร 10 ช่วง และคำเตือนเวลาใกล้รอยต่อ |
| `index.html` | หน้าทดลอง (โหลดสคริปต์จาก `js/`) |
| `build.js` | `node build.js` สร้าง `dist/index.html` แบบไฟล์เดียว |
| `tests/run.js` | `node tests/run.js` ทดสอบกับค่าอ้างอิงที่รู้กันทั่วไป |

ไม่มีไลบรารีภายนอก ใช้ได้ทั้งเบราว์เซอร์และ Node

## ตัวอย่างการใช้

```js
const r = BaziCore.calculate({
  year: 1990, month: 1, day: 15, hour: 10, minute: 30,
  gender: 'M', tz: 7, longitude: 100.5,
  options: { yearChange: 'winterSolstice' } // ค่าอื่นใช้ค่าตั้งต้น
});
r.pillars.year.zh   // '庚午'
r.luck.periods[0]   // วัยจรช่วงแรก
```

## ตัวเลือก (ค่าตั้งต้นตามระบบที่ตกลงกันไว้)

| ตัวเลือก | ค่า |
|---|---|
| `yearChange` | `winterSolstice` ตังจี่ (ค่าตั้งต้น) · `lichun` ลิบชุน · `summerSolstice` แฮ่จี่ |
| `ziHour` | `midnight` วันเปลี่ยน 24.00 น. (ค่าตั้งต้น) · `at23` วันเปลี่ยน 23.00 น. |
| `luckMethod` | `standard` นับจากวันเปลี่ยนปี (ค่าตั้งต้น) · `academic` นับจากวันเกิด ตามตำรา · `proportional` สัดส่วนช่วงเดือน นับละเอียดเป็นวัน |
| `monthSystem` | `standard` เปลี่ยนเดือนที่ 节 · `zhongqi` เปลี่ยนเดือนที่ 中气 |
| `trueSolarTime` | `false` เวลามาตรฐาน (ค่าตั้งต้น) · `true` เวลาสุริยะปรากฏ |
| `southern` | ซีกโลกใต้ (กิ่งเดือนเลื่อน 6) |
| `pregnancyMonths` | 9 (ใช้คำนวณหลักปฏิสนธิ) |

## ผลการตรวจสอบ

ตรวจกับระบบอ้างอิงด้วยวันเกิดสุ่มหลายหมื่นเคส (ครึ่งหนึ่งจงใจให้อยู่ใกล้สารท):

- **เวลาสารท:** ตรงกับตารางอ้างอิงภายใน ±1 นาทีทุกรายการ ช่วง ค.ศ. 1601–2069 (หลังจากนั้นขึ้นกับการคาดการณ์ ΔT)
- **ค่าตั้งต้น (เปลี่ยนปีที่ตังจี่):** 6 เสา ทิศวัยจร อายุเริ่ม และวันเริ่มวัยจรทุกช่วง ตรงกัน 100%
- **เปลี่ยนปีที่ลิบชุน/แฮ่จี่:** ต่างราว 1 ใน 2,000 เคส เฉพาะคนที่เกิดภายในประมาณ 5 ชั่วโมงก่อน/หลังสารทเปลี่ยนปีแต่คนละวันปฏิทิน ระบบอ้างอิงหาเสาปีด้วยค่าเฉลี่ยความยาวปี จึงให้ผลเสาปีกับเสาเดือนขัดกันเอง (เช่น 3 ก.พ. 1733 23:22) ตัวนี้ยึดเวลาสารทจริง
- **โหมดเวลาสุริยะ:** ในวันที่ตรงกับสารท ระบบอ้างอิงเอาเวลามาตรฐานไปเทียบ แต่วันอื่นใช้เวลาสุริยะ ตัวนี้ใช้เวลาสุริยะตลอด ผลจึงต่างกันได้เฉพาะคนที่เกิดในวันสารทนั้น
- **วิธีอายุแบบสัดส่วนช่วงเดือน:** วันเริ่มวัยจรของระบบอ้างอิงมักเร็วกว่า 1 นาที เพราะตัดเศษวินาทีทิ้งตอนแปลงวันที่

## ข้อจำกัดที่ทราบ

- ก่อน 1 เม.ย. 1920 ประเทศไทยใช้เวลา UTC+6:42 ผู้ใช้ต้องใส่ `tz` เอง (แอปขึ้นคำเตือนให้)
- ยังไม่รองรับปฏิทินจูเลียน (ก่อน ค.ศ. 1583)
